# 采音脚本桌面端（Windows）

这是采音脚本 4.0.0 的 **Windows 独立桌面录音端**。它不依赖浏览器控制台，可作为局域网同步录音的主控或客户端，并输出与手机端一致的 WAV 目录和命名。

## 功能范围

桌面端支持导入逐行 JSON TXT 脚本、填写任务和发音人信息、选择电脑麦克风、配置采样率/声道/位深/首尾静音与保存路径。录制完成会自动跳到下一句，最后一句则停留在当前句以便重录；已保存的 WAV 可直接在桌面端播放。它可创建 TCP 主控房间，也可输入手机或电脑主控的 IP、端口和房间口令加入现有房间。

电脑录音配置与多设备同步录音均可折叠。录音配置默认只读，点击“修改配置”后才开放编辑；按钮随即变为“保存配置”，保存后的参数仅应用于后续新录制的 WAV。

主控和客户端仅校验**脚本句数**。脚本名和文本内容可以不同；句数不一致时会显示主控和当前设备的句数。同步控制遵循手机端的开始、停止、上一句、下一句、跳转、播放、重录、取消准备和完成任务命令。

## 文件结构与重录规则

假设在程序中选择的保存根目录是 `D:\Audio`，任务是“任务 A”，发音人是“张三 / 女 / 25”，则录音会保存到：

```text
D:\Audio\record_jxb\wave\张三_女_25岁\任务_A\
```

文件命名固定为：

```text
任务_A_张三_004_20260911-143000.wav
```

重录同一句时，程序会删除该句上一次的输出文件，再保存带当前时间的新文件。因此应用内记录、Windows 输出和手机端共享目录的规则保持一致。

## 在 Windows 10/11 上运行源码

安装 Node.js 22 LTS 与 pnpm 后，在项目根目录执行：

```powershell
cd desktop
pnpm install
pnpm start
```

首次录音时允许 Windows 麦克风权限。若电脑作为主控，Windows 防火墙弹窗出现时应允许“采音脚本桌面端”在**专用网络**上监听端口 `35679`；电脑和手机需要在同一 Wi-Fi 或热点网络。

## 构建 Windows 安装包

```powershell
cd desktop
pnpm package:win
```

打包输出位于 `desktop\release\`。在未配置代码签名证书的开发构建中，Windows 可能显示来源确认提示；正式分发前应使用组织自己的 Windows 代码签名证书进行签名。

## 验证顺序

先在电脑导入一个两句 TXT 脚本，创建主控房间并确认显示局域网 IP、端口和口令；随后在手机端用同样句数的任务加入。主控点击“进入同步录制”后，再逐项验证开始、停止、句子跳转和完成任务。最后重录同一句，确认旧 WAV 已被替换。
