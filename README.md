# 采音脚本（Script Voice Recorder）

**采音脚本**是一款 Android 优先的逐句文本录音工具。应用以本地数据为主，不要求登录或云端同步，适合按脚本完成带提示词、拼音注音和逐句音频归档的录制任务。

## 主要能力

| 模块 | 功能 |
| --- | --- |
| 脚本导入 | 支持系统选择 TXT，或通过同一局域网的“文件快传”页面上传 TXT 脚本；每一行是一句独立的 JSON 字元数组。 |
| 发音人 | 新建、编辑、切换及删除发音人；有关联任务时会保护性阻止删除。 |
| 逐句录制 | 支持 WAV 无压缩录音；可配置采样率、16-bit / 32-bit 位深、声道、首尾静音与逐句重录。 |
| 录制展示 | 显示提示词、拼音逐字朗读文本、完整音频包络波形与播放进度。波形保留平均能量与瞬态峰值，静音、轻声和强声以不同高度、颜色与间距区分。 |
| 任务流程 | 支持句子跳转、播放、重录；全部录制后仍可重录任意一句，并可选择完成任务退出。 |
| 导出与分享 | 单句 WAV 分享、整包分享、Android 公共媒体库导出，以及局域网浏览器下载已完成 WAV。 |
| 多设备同步（3.0.0） | 一台 Android 手机可创建局域网主控房间，其他已创建同一脚本任务的手机可加入；主控同步下发开始、停止、上一句、下一句、播放和重录指令，并显示设备上线、离线、当前句号和录音状态。 |
| 本地化 | 根据系统语言自动切换中文或英文界面。 |

## TXT 脚本格式

仅支持 `.txt` 文件。**每一行**必须是一个 JSON 数组：`char` 是朗读文字，`pinyin` 是展示在字上方的拼音，`Mark` 是该句提示词。

```json
[{ "char": "你", "pinyin": "nǐ" }, { "char": "好", "pinyin": "hǎo" }, { "Mark": "请自然朗读" }]
```

当相邻句的 `Mark` 内容发生变化时，录制页会播放一次从左到右的提示词水波强调；提示词相同时不会重复播放动效。

## 使用流程

1. 在“发音人”中填写姓名、性别与年龄。
2. 新建录音任务，选择一个 TXT 脚本或打开“文件快传”，并关联发音人。
3. 在录制页查看提示词与带拼音的朗读文本，按开始录制完成当前句。
4. 录制页面会按设置保留首尾静音，并显示可区分静音和有声段的完整波形。
5. 可播放或重录任一句；所有句子完成后，底部同时提供“重新录制本句”和“完成任务”。

## 多设备同步录音（3.0.0）

多设备同步不需要互联网。先让 A 手机和所有录音客户端连接同一 Wi-Fi，或由 A 手机开启热点；然后在**每台手机**中使用相同 TXT 脚本分别新建录音任务。进入 A 手机对应任务的详情页，打开“多设备同步录音”，创建主控房间。页面会显示一个局域网地址和六位房间口令。

随后在 B、C、D 等客户端的对应任务详情页选择“加入已有房间”，输入 A 端显示的地址和口令。主控端会显示每台设备的在线、离线、当前句号、等待、首尾静音、录制、保存、播放和异常状态。进入录制页面后，A 端的开始、停止、上一句、下一句、播放和重录会携带预设执行时间发给客户端，以减小局域网传输带来的起始偏差。

同步房间仅在 A 手机保持应用前台时可用；客户端与主控断开会在双方界面显示离线提示。每台设备仍按其本地发音人和任务目录保存 WAV 录音。本版本已建立双向状态和指令基础，录音文件回传与统一下载将在后续版本扩展。

## 文件快传

“文件快传”会在手机**保持应用前台**时开启一个临时局域网文件管理地址。服务会显式绑定当前 Wi-Fi 的 IPv4 地址，并在显示地址前完成本机 HTTP 连通性检查。首次使用时，应用会引导您在 Android 系统设置中授予**管理所有文件**权限；录音导出和文件管理共用原生 Android 文件 API 写入同一公共根目录，手机与电脑或另一台手机连接到同一 Wi-Fi 后，在对方设备浏览器打开应用显示的完整地址（包含访问口令），即可管理共享存储。

浏览器默认打开录音导出目录：

```text
/storage/emulated/0/record_jxb/wave/
```

用户可从该目录返回共享存储根目录，浏览并管理大多数手机目录。受 Android 系统保护的 `Android/data` 等目录仍不可访问。

| 操作 | 说明 |
| --- | --- |
| 浏览目录 | 默认进入录音目录；支持进入子目录、返回上级目录，并显示当前绝对路径。 |
| 上传与下载 | 可多选批量上传单个不超过 15 MB 的文件，也可下载单个文件。目录下载会在手机原生文件系统生成临时 ZIP 并以分块数据传输给浏览器，不再把整个目录加载到应用内存。 |
| 新建与删除 | 可在当前目录新建文件夹，并删除不再需要的文件或目录；删除不可恢复。 |
| 查看录音位置 | 手机端快传页会显示当前默认录音目录；浏览器端可以直接下载已完成的 WAV。 |

该地址与口令在停止文件快传、离开快传页面并停止服务或关闭应用后失效。请勿将其提供给不受信任的设备。

## 本地文件与导出

脚本和录音会保存在应用私有目录，以便任务管理、播放和重录。每句录音保存后，应用也会尝试导出到 Android 公共媒体库中的以下分层目录：

```text
record_jxb/wave/<发音人信息>/<任务名>/
```

若系统媒体库拒绝公共目录写入，应用内录音仍会保留并可播放、重录和分享。

## 开发

```bash
pnpm install
pnpm dev
```

常用检查命令：

```bash
pnpm check
pnpm test
```

需要在 Windows 本地生成 APK、绕过 EAS 云端构建配额时，请阅读 [`docs/windows-local-apk-build.md`](docs/windows-local-apk-build.md)。

项目基于 Expo SDK 54、React Native、Expo Router、`expo-audio`、`react-native-audio-api`、`react-native-tcp-socket`、`expo-crypto` 与 AsyncStorage 构建。WAV 录音、局域网文件快传和多设备同步均依赖 Android 原生模块：修改后必须重新构建并安装 APK，不能在网页预览或 Expo Go 中完整验证。

## 隐私说明

应用默认将发音人信息、脚本任务和录音保存在设备本地。除用户主动通过系统分享功能选择外，应用不会将录音自动上传到远程服务。
