# 采音脚本（Script Voice Recorder）

**采音脚本**是一款 Android 优先的逐句文本录音工具。应用以本地数据为主，不要求登录或云端同步，适合按脚本完成带提示词、拼音注音和逐句音频归档的录制任务。

## 主要能力

| 模块 | 功能 |
| --- | --- |
| 脚本导入 | 支持系统选择 TXT，或通过同一局域网的“文件快传”页面上传 TXT 脚本；每一行是一句独立的 JSON 字元数组。 |
| 发音人 | 新建、编辑、切换及删除发音人；有关联任务时会保护性阻止删除。 |
| 逐句录制 | 支持 WAV 无压缩录音；可配置采样率、16-bit / 32-bit 位深、声道、首尾静音与逐句重录。 |
| 录制展示 | 显示提示词、拼音逐字朗读文本、完整音频包络波形与播放进度。静音段与有声段以不同高度和颜色区分。 |
| 任务流程 | 支持句子跳转、播放、重录；全部录制后仍可重录任意一句，并可选择完成任务退出。 |
| 导出与分享 | 单句 WAV 分享、整包分享、Android 公共媒体库导出，以及局域网浏览器下载已完成 WAV。 |
| 本地化 | 根据系统语言自动切换中文或英文界面。 |

## TXT 脚本格式

仅支持 `.txt` 文件。**每一行**必须是一个 JSON 数组：`char` 是朗读文字，`pinyin` 是展示在字上方的拼音，`Mark` 是该句提示词。

```json
[{ "char": "你", "pinyin": "nǐ" }, { "char": "好", "pinyin": "hǎo" }, { "Mark": "请自然朗读" }]
```

当相邻句的 `Mark` 内容发生变化时，录制页会播放一次从左到右的提示词水波强调；提示词相同时不会重复播放动效。

## 使用流程

1. 在“发音人”中填写姓名、性别与年龄。
2. 新建录音任务，选择一个 TXT 脚本或打开“文件快传”，并关联发音人。
3. 在录制页查看提示词与带拼音的朗读文本，按开始录制完成当前句。
4. 录制页面会按设置保留首尾静音，并显示可区分静音和有声段的完整波形。
5. 可播放或重录任一句；所有句子完成后，底部同时提供“重新录制本句”和“完成任务”。

## 文件快传

“文件快传”会在手机**保持应用前台**时开启一个临时局域网地址。将手机与电脑或另一台手机连接到同一 Wi-Fi 后，在对方设备浏览器打开应用显示的完整地址（包含访问口令），即可执行以下读写操作：

| 操作 | 说明 |
| --- | --- |
| 上传脚本 | 上传不超过 3 MB 的 `.txt` 脚本；应用会校验每行 JSON 字元数组格式，并可直接选择该脚本建立或更换任务。 |
| 下载录音 | 浏览、下载已完成的 WAV 录音；为防止前台传输占用过高，单文件下载上限为 45 MB。 |

该地址与口令在停止文件快传、离开快传页面并停止服务或关闭应用后失效。请勿将其提供给不受信任的设备。

## 本地文件与导出

脚本和录音会保存在应用私有目录，以便任务管理、播放和重录。每句录音保存后，应用也会尝试导出到 Android 公共媒体库中的以下分层目录：

```text
record_jxb/wave/<发音人信息>/<任务名>/
```

若系统媒体库拒绝公共目录写入，应用内录音仍会保留并可播放、重录和分享。

## 开发

```bash
pnpm install
pnpm dev
```

常用检查命令：

```bash
pnpm check
pnpm test
```

项目基于 Expo SDK 54、React Native、Expo Router、`expo-audio`、`react-native-audio-api`、`expo-http-server` 与 AsyncStorage 构建。WAV 录音和局域网文件快传均依赖 Android 原生模块：修改后必须重新构建并安装 APK，不能在网页预览或 Expo Go 中完整验证。

## 隐私说明

应用默认将发音人信息、脚本任务和录音保存在设备本地。除用户主动通过系统分享功能选择外，应用不会将录音自动上传到远程服务。
