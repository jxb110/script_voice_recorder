# Liquid Glass 交互参考笔记

本轮将用户提供的 AndroidLiquidGlass 公开示例作为**视觉与交互参考**，不复制其源代码、资源或特定实现细节。

| 参考组件 | 将采用的设计原则 | 在采音脚本中的落点 |
| --- | --- | --- |
| LiquidButton | 双层高光边、半透明折射底色、按下时的小幅内缩与高光收束 | 主操作、危险操作、工具按钮 |
| LiquidToggle | 磨砂轨道、带高光的液滴拇指、状态切换时的柔和位移 | 分段选择与可切换状态控件 |
| LiquidSlider | 低对比玻璃轨道、清晰液态进度、可聚焦的发光拇指 | 字号滑条与设置页数值控制 |
| LiquidBottomTabs | 悬浮玻璃壳体、活动胶囊、图标前景高光和克制的选中迁移动效 | 任务、脚本、设置底部导航 |

实现约束：所有重构仅调整 React Native 呈现层；录音、WAV、文件快传、局域网同步、导航、数据读写及既有回调保持不变。Android 长列表避免叠加高强度真实模糊，以半透明层、高光边和柔阴影降级实现。
