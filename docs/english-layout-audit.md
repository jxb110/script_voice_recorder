# 英文界面小屏布局审查记录

## 设置页

- `Current recording profile` 的英文标题与说明会占用更宽空间。
- 首端/尾端静音摘要当前采用横向标签与数值并排，窄屏下标签与数值会相互挤压，需改为每项独立的纵向信息卡。
- 设置页保持单屏策略，因此优先压缩卡片间距、使用弹性宽度、允许说明文本换行，而不增加整页滚动。

## 任务首页

- 英文副标题已有双行约束，但创建任务按钮、统计标签和任务元数据需要添加 `flexShrink`、行数限制或可控换行，避免与图标争夺宽度。
- 顶部发音人按钮应保持固定宽度，标题文本区域使用 `minWidth: 0` 和弹性收缩。

## 后续页面

- 继续检查 Scripts、任务详情和录制页的行内标签、图标按钮和底部关键操作；统一采用安全区、最小宽度、文字截断或受控换行原则。

## 脚本与任务详情

- Scripts 页的任务卡需要让任务副标题和元数据文本可收缩或截断，避免与固定宽度删除按钮和前导图标重叠；空状态的导入按钮需要允许英文长文字在其内容宽度内完整显示。
- 任务详情的“Replace script”“Delete task”“Continue recording”等英文操作需要采用可缩放的双按钮文字样式，长锁定提示应在卡片内换行。句子列表标题与提示应避免同一行互相挤压。

## 录制页

录制页已对顶部发音人信息、字号控制和值、设备名称浮层采用 `minWidth: 0`、弹性宽度和安全区约束。修复时须保留这些约束，并为底部三工具按钮和双主操作按钮补充英文文字的收缩与最小字号策略，避免影响当前录制和同步控制流程。

## 新建任务与发音人

新建任务页的“Create a speaker”与“Select a speaker”需要在窄屏中允许按钮换行或收缩；脚本文件名、导入说明和预览标题需要限制行数。发音人页的标题区域、姓名卡片与编辑弹层标题同样需要弹性宽度、行数约束及固定图标的收缩隔离。
