# 百度网盘 Android SDK 自动上传调研记录

## 已核对的官方文档

- 基础模块：<https://pan.baidu.com/union/doc/sdk/android/%E5%9F%BA%E7%A1%80%E6%A8%A1%E5%9D%97/>
- 文件传输模块—上传：<https://pan.baidu.com/union/doc/sdk/android/%E6%96%87%E4%BB%B6%E4%BC%A0%E8%BE%93%E6%A8%A1%E5%9D%97-%E4%B8%8A%E4%BC%A0/>

## 初步结论

1. 官方 Android SDK 将基础模块、文件操作和文件传输上传模块分开提供，说明原生 Android 端具备应用内上传能力。
2. 基础模块需要设置账户信息、Token、Token 失效监听和网络实现，并在使用后初始化/反初始化 SDK。
3. 上传模块提供 `startUpload(uris, path, callback)`；其 `path` 参数就是网盘目标路径，因此支持上传到用户指定目录。模块还提供上传状态回调、暂停、恢复、删除和查询任务列表能力。
4. 上传配置默认并发数为 2，最大可配置为 5；这适合把每句 WAV 加入队列后由 SDK 控制传输，而非阻塞下一句录音。
5. Android 授权接入前需要百度账号、实名认证、控制台创建应用并获得凭证，且官方文档要求通过邮件提交应用名、场景、AppID、AppKey、正式包签名和包名，审核预计 6–10 个工作日。
6. 授权使用 `basic,netdisk` scope；SDK 授权回调需交换 access token。文档注明 access token 有效期为 30 天，过期后需要用 refresh token 更新。

## 当前应用接入原则

- 不上传任何录音，直至用户完成百度授权并显式开启自动上传。
- 仅在 WAV 文件成功保存后将其放入上传队列；录音成功不依赖网络上传成功。
- 指定网盘目录应由用户选择或填写，并经过可写性验证；建议默认 `/apps/采音脚本/`，用户可改为自己的目标目录。
- 失败任务需要本地持久化，以便在网络恢复或用户手动重试时继续上传；优先复用 SDK 的任务查询、暂停与恢复能力。
- Expo 当前需要新增原生 Android bridge 或迁移到原生模块集成，不能只用 JavaScript 直接调用 AAR；因此必须重新构建 APK。

## 平台目录与配额约束

1. 百度网盘开放平台将“应用数据存储”列为官方场景，支持把应用或设备产生的数据备份到用户个人网盘。
2. 新建应用默认处于未审核状态：最多 10 名用户、接口频率 10 次/小时。逐句完成即上传会很快耗尽该频率，不能在未审核状态下直接启用该模式。
3. 第三方应用默认只能操作用户授权后的应用目录，通常是 `/apps/{appname}`（在网盘界面显示为“我的应用数据/{appname}”）。因此“指定地址”不能是任意网盘路径；默认目标必须是应用目录，其他目录须在平台授权能力明确允许并获得用户授权后才能使用。
4. 个人用途应用可免审核但最多 10 用户；公开发布则需要上线审核，正式额度按白名单方式分配。

## 建议的应用接入架构

1. 设置页增加一个默认关闭的“百度网盘自动上传”开关、授权入口、当前授权账号、目标目录说明和上传队列状态；用户未授权或未开启时绝不触发网络上传。
2. 单句录制应先走现有 `persistRecording → exportRecordingToPublicWaveDirectory → 更新本地任务` 流程。只有 WAV 已稳定保存后，才将 `recordingUri`、文件名、目标目录和重试信息加入本地持久化上传队列。
3. 原生 Android bridge 封装官方 AAR 的 `startUpload`、状态监听、暂停、恢复、删除和任务查询能力。队列默认串行或低并发，禁止阻塞本地保存和下一句录制。
4. OAuth 的 AppKey 可放入原生应用配置；SecretKey 绝不放入 APK。授权码换取/刷新 Token 应通过受保护的后端端点完成，手机只持有加密保存的用户 access token/刷新凭据或短期会话。
5. 任何失败均不影响本地录音；记录失败原因并提供“重试全部、重试单条、暂停上传、取消上传”入口。网络不可用、令牌失效、配额受限应进入等待或需重新授权状态。
6. 未审核应用不应启用“逐句即时上传”，因为官方 10 次/小时频率上限不足以覆盖连续录音。原型阶段应使用手动批量上传，或等待上线审核和所需配额获批后再启用逐句自动上传。
